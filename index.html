Sobre

Trabalho com desenvolvimento full-stack, com foco em JavaScript, e mantenho a Linhagem SPARK — uma coleção de projetos pessoais que resolvem problemas reais do dia a dia de quem programa, do gerenciamento de notas ao aprendizado de comandos de terminal.

HTML5 CSS3 JavaScript PHP Git & GitHub Markdown

Linhagem SPARK

Um hub de engenharia dedicado a devolver o controle tecnológico ao usuário final — ferramentas que operam sob a premissa da independência total, sem depender de nuvem ou conectividade constante.

Arquitetura Offline-First

Software funcional em qualquer cenário. As ferramentas operam de forma autônoma, sem que a falta de conexão vire um obstáculo.

Soberania e Privacidade

Processamento no lado do cliente. Os dados pertencem ao usuário e permanecem no seu próprio dispositivo.

Utilidade Pragmática

Ferramentas de precisão: cada linha de código resolve problemas reais com máxima eficiência e mínimo ruído visual.
