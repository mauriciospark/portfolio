# Sobre o Projeto — Visão Geral e Propósito (Linhagem SPARK)

Este repositório é o portfólio oficial de Mauricio Spark (marca SparkMauricio), ponto de entrada da Linhagem SPARK na web.

## História e Motivação

A Linhagem SPARK nasceu para devolver controle tecnológico ao usuário: ferramentas que funcionam no cliente, sem dependência constante de nuvem. Faltava um endereço único que reunisse a pessoa, a marca e os produtos (coreIcons, registros, syntax, score) com a mesma linguagem visual e os mesmos valores.

O portfólio resolve esse gap. Em vez de um currículo genérico ou de um site acoplado a CMS, ele apresenta o trabalho em HTML puro, CSS e JavaScript — o mesmo nível de autonomia que a linhagem cobra dos próprios produtos.

## Filosofia da Marca

Valores da Spark Mauricio aplicados a este site:

- **Privacidade:** nenhum formulário, cookie de rastreio ou banco remoto. O visitante não envia dados pessoais ao projeto. A única chamada de rede opcional é a API pública do GitHub para estrelas dos repositórios listados.
- **Eficiência:** páginas estáticas, CSS enxuto, script mínimo. Sem framework, sem build obrigatório.
- **Autonomia:** o site abre localmente, em GitHub Pages ou em qualquer host estático. A falta de backend não impede a leitura completa do conteúdo.
- **Design:** tipografia Display/Mono, paleta escura com acento dourado, contraste e hierarquia claros, ruído visual reduzido.

## Público-Alvo

- Recrutadores e empresas que avaliam um desenvolvedor full-stack com foco em JavaScript e projetos open-source
- Desenvolvedores que buscam as ferramentas da Linhagem SPARK e precisam de contexto rápido
- Colaboradores potenciais que querem entender pilares técnicos antes de abrir um repositório específico

O valor está na clareza: quem chega entende o posicionamento, vê evidência (projetos ao vivo) e consegue contato em poucos cliques.
